# XOXO — My Bunny 🐰💜

## Mise en ligne sur GitHub Pages

1. Crée un dépôt GitHub.
2. Ajoute tous les fichiers de ce dossier à la racine du dépôt.
3. Dans **Settings → Pages**, choisis la branche **main** et le dossier **/(root)**.
4. Ouvre le lien GitHub Pages créé.

## Utilisation sans connexion

Le jeu possède un **mode hors connexion** grâce au fichier `service-worker.js`.

⚠️ **Important :** après la mise en ligne, ouvre le jeu **au moins une fois avec une connexion Internet**. Le navigateur enregistrera alors le jeu et ses fichiers essentiels. Après cette première ouverture, XOXO pourra être lancé sans connexion Internet.

Pour une expérience similaire à une application sur iPhone : ouvre le jeu dans Safari, appuie sur **Partager → Sur l'écran d'accueil**.
